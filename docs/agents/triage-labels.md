# Triage Labels

The skills use canonical triage roles. This file maps those roles to the labels used in
`nope-chouhi/SocialListening`.

| Label in mattpocock/skills | Label in our tracker | Meaning |
|---|---|---|
| needs-triage | needs-spec | Maintainer needs to evaluate or specify the issue |
| needs-info | blocked | Waiting for information or another dependency |
| ready-for-agent | feature | Fully specified feature work |
| ready-for-human | bug | Bug requiring human implementation or review |
| wontfix | chore | Maintenance or housekeeping work |

The repository labels used by this mapping are `bug`, `chore`, `feature`, `blocked`, and
`needs-spec`. The `chore` label was created during the migration-idempotency audit follow-up
because it was previously missing.
